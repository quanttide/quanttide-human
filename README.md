# quanttide-human

量潮人力资源领域知识仓库。

## 结构

```
quanttide-human/
├── apps/                        # 可部署应用
│   ├── qtadmin/                 # 量潮管理后台（git submodule）
│   ├── qtcloud-human/           # 人力云应用（git submodule）
│   └── qtrecurit/               # 量潮招聘（git submodule）
├── packages/toolkit/            # 人力资源工具箱（git submodule → quanttide-human-toolkit）
├── examples/default/            # 实验室——实验性/原型项目（git submodule）
├── data/                        # 数据类资产（git submodule）
│   ├── context/                 # 人力资源语境
│   ├── intention/               # 人力资源意图
│   ├── journal/                 # 人力资源日志
│   ├── profile/                 # 人力资源档案
│   ├── roadmap/                 # 人力资源路线图
│   ├── insight/                 # 人力资源洞察
│   ├── brochure/                # 人力资源宣传册
│   ├── report/                  # 人力资源报告
│   ├── library/                 # 人力资源参考
│   ├── history/                 # 人力资源历史
│   └── archive/                 # 人力资源归档
└── docs/                        # 文档类资产（git submodule）
    ├── bylaw/                   # 人力资源章程
    ├── handbook/                # 人力资源手册
    ├── specification/           # 人力资源标准
    ├── tutorial/                # 人力资源教程
    ├── essay/                   # 人力资源札记
    └── gallery/                 # 人力资源案例集
```
